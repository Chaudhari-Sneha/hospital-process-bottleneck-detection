# Groq (hosted, free tier) - NO PACKAGE REQUIRED.
#   The default backend, and the only one that works on a deployed server.
#   It speaks an OpenAI-compatible API, which src/15 already reaches over
#   stdlib urllib. Needs only a free key from console.groq.com, placed in a
#   gitignored `.env` as GROQ_API_KEY=... or exported into the environment.
#   `python src/check_api_key.py` verifies a key and lists the models it may use.
